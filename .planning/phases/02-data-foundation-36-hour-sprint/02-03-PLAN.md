| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-08 | Tampering/Information Disclosure | XSS via Supabase row content rendered in the UI | mitigate | All row strings render as plain React text children (JSX `{value}`) — no `dangerouslySetInnerHTML` anywhere in the migrated pages. React escapes by default. |
