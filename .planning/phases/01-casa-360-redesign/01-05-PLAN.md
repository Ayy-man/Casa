| mock-data string -> rendered agent detail | Agent-log strings render into the agent detail pages and the activity feed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-12 | Tampering / Open Redirect | `redirect(`/vault/properties/${params.id}`)` in the legacy `[id]` stubs | mitigate | The redirect target is a fixed `/vault/...` prefix with only the path segment interpolated — `params.id` cannot escape to an absolute/external URL because it is a single Next.js dynamic segment and the prefix is a server-controlled relative path. Not an open-redirect: the destination host is always same-origin. |
| T-01-13 | Tampering / XSS | agent detail pages + activity feed rendering mock-data strings | mitigate | All agent-log strings render as plain React text children — no `dangerouslySetInnerHTML` in any agent-logs page. |

</threat_model>
